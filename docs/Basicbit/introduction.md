# Introduction

## Introduction
The Smarthon Basic:bit is an essential expansion board that enhances the functionality of the Micro:bit platform. This innovative board allows users to effortlessly connect a variety of sensors and actuators without soldering, making it an ideal choice for educators, hobbyists, and professionals alike.
<P>
Equipped with 13 standard GVS sockets, the Basic:bit enables simultaneous connections of multiple sensors, facilitating the collection and analysis of diverse data in real time. Additionally, the board features specialised independent sockets for particular devices, such as distance sensors, enabling the integration of both digital and analogue I/O systems. The inclusion of I2C device support further broadens the Micro: bit's capabilities, opening new avenues for creativity and experimentation.
<P>
Furthermore, the Basic:bit includes a built-in buzzer that allows users to incorporate sound generation into their projects, enriching the interactive experience. Overall, the Smarthon Basic:bit expansion board is a powerful tool that empowers users to explore and innovate, making it an invaluable addition to any Micro:bit project.built into the board to provide sound generation.

## Detail Hardware Description

<H3>Micro:bit edge connecter</H3><BR>

![pic](images/Introduction/image9.png)
<P>Provide the socket for the Micro:bit to install. Follow the instruction icon right about that to install the Micro:bit to the expansion board.

<H3>USB power port & Switch</H3><BR>

![pic](images/Introduction/image2.png)
<P>Provide 5V USB MICRO B port to power on the expansion board and Micro:bit.

<H3>Buzzer & Switch</H3><BR>

![pic](images/Introduction/image7.png)
<P>The basic:bit built in a Passive Buzzer on the board, which connected to P0. Using the program can generate different tone of sound.
Since each I/O pin should be only serve for one sensor/actuators at the same time, so you should pulling the switch down (to the sound icon) when using buzzer, otherwise pulling the switch up (to the mute icon) to avoid the interrupt from buzzer to P0.

<H3>Micro:bit lead out Pins</H3>

![pic](images/Introduction/image15.png)
<P>The Lead Out from the Micro:bit I/O pins provide a great expansion feature for the Micro:bit. The user can connect up to 13 sensors/actuators simultaneously. Each independent GVS socket makes the connection more convenient.

<H3>4-Pin Module Port</H3><BR>

![pic](images/Introduction/image14.png)
<P>On the basic:bit, two ports are reserved for the 4 Pins Module. Each port can connect to some sensors or actuators which required use of two I/O Pins at the same time, such as a Distance Sensor. In total, there are 4 I/O Pins being used, they are P12, P13, P14, P15 respectively.

<H3>I2C Port</H3><BR>

![pic](images/Introduction/image13.png)
<P>Since the Micro:bit supports the I2C protocol, basic:bit provides five I2C ports (two female ports reserved for the OLED Module and LCD display) to connect I2C peripherals, enabling the IoT project to access more sensors/actuators.

<H3>Rapid Access Port</H3><BR>

![pic](images/Introduction/image16.png)
<P>Some GVS sensors that provide the Rapid Insert Pin, they can be used on the Rapid Access Port. It does not need to use the cable to connect the sensor, simplifying the product in the application.

<H3>Crocodile Pin</H3><BR>

![pic](images/Introduction/image10.png)
<P>For users who use the crocodile cable clips to connect parts, basic:bit reserved 5 Pins for easier access. There are 3 Pins from GVS Ports 0, 1, and 2, and 2 Pins for 3V and Ground.
